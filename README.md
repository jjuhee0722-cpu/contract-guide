# 국가기관 계약방법 조회 웹사이트

국가기관 공무원이 물품구매·용역 발주 시 금액에 따른 계약방법과 근거 법령을 즉시 확인할 수 있는 정적 웹사이트입니다.

## 사용 방법

1. `index.html`을 브라우저로 열거나 아래 배포 방법으로 공유합니다.
2. 물품 구매 / 용역 발주 중 하나를 선택합니다.
3. 추정가격을 입력하면 계약방법·법령 조문·절차·주의사항이 자동으로 표시됩니다.

## 배포 방법

### GitHub Pages (권장)
1. GitHub에 저장소를 만들고 이 폴더 전체를 업로드합니다.
2. Settings → Pages → Branch: main / (root) 설정
3. 발급된 URL을 부서원과 공유합니다.

### Netlify (드래그앤드롭)
1. [netlify.com](https://netlify.com) 접속
2. "Deploy without connecting to Git" 선택
3. 폴더 전체를 드래그앤드롭 → 즉시 URL 발급

### 로컬 / 내부망 (오프라인)
- `index.html`을 더블클릭하면 바로 실행됩니다. (`data/contracts.js` 폴백 사용)
- 내부 웹서버(IIS, nginx 등)에 폴더를 복사해도 됩니다.

## 법령 개정 시 데이터 수정 방법

법령 기준 금액이나 조문 번호가 바뀌면 **`data/contracts.json`** 파일만 수정하면 됩니다.  
오프라인 환경에서는 `data/contracts.js`도 동일하게 수정해주세요.

### 주요 수정 항목

| 항목 | 필드 | 예시 |
|---|---|---|
| 금액 기준 변경 | `minAmount`, `maxAmount` | `"maxAmount": 20000000` |
| 조문 번호 변경 | `legalBasis[].article` | `"제26조 제1항 제5호"` |
| 절차 추가/삭제 | `procedures[]` 배열 | `"견적서 2부 이상 징구"` |
| 주의사항 수정 | `warnings[]` 배열 | |
| 최종 업데이트일 | `meta.lastUpdated` | `"2025-01-01"` |

### 금액 구간 기준 (현행)

| 구분 | 금액 | 계약방법 | 근거 조문 |
|---|---|---|---|
| 물품·용역 | 2,000만원 이하 | 수의계약 (1인 견적) | 시행령 제26조 제1항 제5호 가목 |
| 물품·용역 | 2,000만원 초과 ~ 5,000만원 이하 | 수의계약 (2인 이상 견적) | 시행령 제26조 제1항 제5호 나목 |
| 물품·용역 | 5,000만원 초과 ~ 2억원 이하 | 제한경쟁입찰 | 시행령 제21조 |
| 물품·용역 | 2억원 초과 | 일반경쟁입찰 | 법 제7조 제1항 |

> ⚠ 조달청 고시 국제입찰 기준금액(약 2억 1,700만원)은 매년 변경될 수 있습니다.

## 파일 구조

```
contract-guide/
├── index.html           # 메인 페이지
├── css/style.css        # 스타일 (반응형, 인쇄)
├── js/app.js            # 핵심 로직
├── data/
│   ├── contracts.json   # 법령 데이터 (정기 수정 대상)
│   └── contracts.js     # 오프라인 폴백 (contracts.json과 동일 내용)
└── README.md
```
